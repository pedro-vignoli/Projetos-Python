# Projeto Criptografia

Interactive terminal program based on the Caesar cipher.

- [1] Encrypt: shifts each character by a key you choose.
- [2] Decrypt: tries keys 1 to 25 (brute force) and prints every result.
- [3] Quit.

Run:

```bash
python main.py
```

Example:

```text
[1] Criptografia [2] Descriptografar [3] Sair
Escolha sua opção: 1
Digite sua mensagem: Olá Mundo
Digite o número da chave: 3
Mensagem criptografada: Roã#Pxqgr
```

# Português

Programa interativo de terminal baseado na Cifra de César.

- [1] Criptografar: desloca cada caractere por uma chave que você escolhe.
- [2] Descriptografar: testa as chaves de 1 a 25 (força bruta) e mostra todos os resultados.
- [3] Sair.

Executar:

```bash
python main.py
```
