# Projeto Jogo do Adivinha

Terminal number guessing game. The program picks a number from 1 to 100 and you guess until you get it, with a hint after each try.

- "Sobe um pouco mais" if the guess is too low, "Desce um pouco" if too high.
- Warning when the guess is outside 1 to 100.
- Best-score record kept between rounds of the same session.
- Asks to play again at the end of each round.

Concepts: nested `while` loops, `if`/`elif`/`else`, the `random` module, input handling and state between rounds.

Run:

```bash
python jogo.py
```

Standard library only.

# Português

Jogo de adivinhar número no terminal. O programa sorteia um número de 1 a 100 e você chuta até acertar, com uma dica a cada tentativa.

- "Sobe um pouco mais" se o palpite for baixo, "Desce um pouco" se for alto.
- Aviso quando o palpite está fora de 1 a 100.
- Recorde de menor número de tentativas mantido entre as rodadas da mesma sessão.
- Pergunta se quer jogar de novo ao fim de cada rodada.

Conceitos: `while` aninhados, `if`/`elif`/`else`, módulo `random`, tratamento de entrada e estado entre rodadas.

Executar:

```bash
python jogo.py
```

Apenas biblioteca padrão.
