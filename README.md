# Portfólio de Projetos - Tecnologia em Inteligência Artificial

Repositório centralizado com os projetos práticos desenvolvidos durante o **segundo semestre de 2026** no curso superior de tecnologia (**Tecnólogo**) em **Inteligência Artificial**.

Estes projetos demonstram a aplicação prática de conceitos fundamentais de desenvolvimento de software, integração com APIs de Inteligência Artificial e algoritmos de segurança/criptografia.

---

## 📂 Projetos Disponíveis

### 1. Assistente de IA - Professor de Programação
- **Descrição:** Um assistente interativo baseado em terminal que utiliza modelos de linguagem via **OpenRouter** (`openai` SDK). O bot foi configurado com uma persona especializada para atuar como um professor de programação paciente e didático, auxiliando em dúvidas de código, conceitos e boas práticas.
- **Tecnologias:** Python, OpenRouter API.

### 2. Programa de Criptografia Simples (Cifra de César)
- **Descrição:** Uma ferramenta de terminal interativa desenvolvida para criptografar e descriptografar mensagens utilizando o conceito clássico da Cifra de César. Inclui recursos de deslocamento por chave personalizada e quebra por força bruta.
- **Tecnologias:** Python, Estruturas de Repetição e Manipulação de Strings.

---

## 🛠️ Tecnologias e Ferramentas Gerais
- **Linguagem:** Python 3.x
- **APIs & Integrações:** OpenRouter / OpenAI Client SDK
- **Controle de Versão:** Git & GitHub

## ⚙️ Como Utilizar

Cada projeto possui sua própria pasta ou estrutura individual com seu respectivo script principal (`main.py`) e orientações detalhadas de execução. Em suma, para rodar qualquer um deles:

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   cd seu-repositorio
   ```
2. Instale as dependências necessárias (quando houver):
   ```bash
   pip install openai
   ```
3. Execute o script desejado:
   ```bash
   python main.py
   ```
