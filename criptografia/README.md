# Criptografia Simples em Python (Cifra de César)

Este projeto é um programa interativo de criptografia e descriptografia via terminal desenvolvido em Python, baseado no conceito da Cifra de César.

---

## 🚀 Funcionalidades

- **Criptografia [1]:** Desloca os caracteres de uma mensagem informada utilizando uma chave numérica escolhida.
- **Descriptografia [2]:** Testa automaticamente todas as chaves possíveis (de 1 a 26) para revelar a mensagem oculta (força bruta).
- **Menu Interativo:** Loop contínuo de opções até que o usuário decida sair.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
